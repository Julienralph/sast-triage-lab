# Demo target

Ceci est la cible de démonstration utilisée pour valider la boucle de travail du MVP.

L'objectif est de simuler un petit programme avec:
- une entrée non fiable,
- un état sensible,
- une condition de sécurité non respectée,
- une violation qui peut être détectée avec instrumentation + fuzzing.

Le développement de cette cible devra être simple, reproductible et facile à comprendre pour un portfolio.
